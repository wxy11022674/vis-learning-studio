# 昕品重制 · 可视化学习空间

《可视化导论》课程网站重构作业。原站：https://cinger007.github.io/vis/

## 打开网站

本项目无依赖、无构建步骤。双击 `dist/index.html` 即可使用主要功能；推荐用本地服务器运行，以获得更完整的剪贴板等浏览器能力。

Windows 上双击根目录的 `start-preview.cmd`，即可在后台启动预览；启动器会检查 HTTP 服务是否响应，并复用已经启动的本项目服务。服务仅监听本机，不随启动窗口关闭而退出。日志和进程编号保存在 `artifacts/preview.*`。停止服务可运行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/start-preview.ps1 -Stop`。

也可以在终端中使用以下前台命令，使用期间保持终端运行：

```sh
python -m http.server 8765 --bind 127.0.0.1 --directory dist
```

然后访问 http://127.0.0.1:8765 。如果 8765 被占用，可以改用其他端口。

## 2.1 讲解—代码—图形联动

五章全部 27 个小节的“概念讲解”页均加入联动学习区。点击正文中带下划线的关键词，或选择联动区的知识点，相关代码行和图形元素会同时高亮；点击代码和图形也可以反查知识点。改动滑块、下拉框与开关时，参数、图形和数据表即时更新。

- 第一章：数据清洗、DIKW、属性编码、筛选聚合、enter/update/exit 集合。
- 第二章：可视化流程、分类聚合、树的坐标布局、捕获与冒泡路径。
- 第三章：HSL、三类色带、Lab 色域切片、色相搭配、科研配色、彩虹错误对照、焦点强调、冗余编码。
- 第四章：数据域到像素、线性与对数坐标、插值、绘图区高度、Marching Squares。
- 第五章：时间粒度、缺失值处理、日历热图、周期螺旋、Storyline。

代码面板展示实际用于计算图形的 JavaScript 函数和当前参数。复制后的代码可以独立计算 `result.marks`、`result.table` 等结果；页面的 SVG 绘制器据此显示图形。页面不执行用户输入的任意代码，也无需服务器模型或网络请求。参数在本次页面会话中保留，刷新后恢复默认值；每节均有重置按钮和操作任务。

所有示例注明数据来源与简化范围。颜色编码使用边框高亮，不通过降低透明度改变色块颜色；灰度预览明确区别于色觉缺陷模拟。已有笔记、完成标记与收藏保持原有存储格式。

## 验证

```sh
npm run check
```

联动计算检查覆盖 27 个小节、280 组参数组合，并验证复制代码与图形计算结果一致。DOM 交互检查覆盖知识点、代码、图形、全部控件、重置、键盘选择、复制，以及笔记和完成进度。运行 DOM 检查需安装仅供开发验证的 LinkeDOM：

```sh
npm install --prefix artifacts/dom-qa --no-save --package-lock=false linkedom
npm run check:dom
```

`artifacts/` 不参与发布；该 DOM 检查不替代浏览器中的视觉排版检查。

`browser-check.cjs` 使用本机已安装的 Playwright 与 Chrome 做端到端验证，不是网站运行依赖。使用时可通过 `PLAYWRIGHT_PACKAGE`、`BROWSER_EXECUTABLE`、`SITE_URL` 环境变量指定路径与地址。

## 部署

源码仓库：https://github.com/wxy11022674/vis-learning-studio

GitHub Pages 地址：https://wxy11022674.github.io/vis-learning-studio/

`main` 分支保存源码，`codex/github-pages` 分支根目录用于网页发布。在 GitHub 仓库的 Settings → Pages 中选择 Deploy from a branch，并指定 `codex/github-pages` 与 `/ (root)`。

更新网页时先运行 `npm run check`，再运行 `node scripts/prepare-pages.mjs`。将生成的 `artifacts/pages/` 内容更新到发布分支根目录并推送，GitHub Pages 会重新构建。整理脚本只复制主站所需的 12 个文件与 `.nojekyll`；它不执行 Git 提交或推送。

所有站内资源使用相对路径，导航使用 hash，支持 `/vis-learning-studio/` 项目子路径。学习记录仍保存在访问者本地浏览器，不上传 GitHub。

## 内容与数据说明

原课程来源：中国石油大学（华东），授课教师李昕，主要参考教材陈为《可视化导论》。本站沿用原站五章与 27 个小节的知识组织结构，导学文字、简化代码、练习题、界面和实验实现为重构新编内容。完整讲解和原课程演示通过每章的链接访问；本站不冒充原课程官方版本。

实验中的学生人数、阅读页数、月度观测和日历活动均为教学合成数据，不能用于真实结论。日历数据固定生成为 2026 年 365 天。灰度预览只检查明暗层级，不是色觉缺陷模拟。代码页中的 D3 示例需要 D3 环境；本站实验本身不依赖 D3 或网络 CDN。

学习记录仅存储在当前浏览器的 localStorage，不上传服务器，不跨设备同步。导入备份会合并完成项、收藏与答案，并替换备份中同名小节的笔记。建议在导入前先导出当前记录。
